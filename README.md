# ml-overoptimism-publication-bias

Code and reproducibility materials for experiments studying overoptimism, publication bias, data leakage, and overfitting in machine learning-driven science.

This repository provides cleaned notebooks and documentation associated with the paper:

**Unraveling overoptimism and publication bias in ML-driven science**

Archived code is available on Figshare:  
https://doi.org/10.6084/m9.figshare.27093958
